# nitrog3d

A blender extension to import and export Nintendo DS NSBMD files.

## Features

The currently implemented (and planned) features are as follows:

- [x] Import of NSBMDs with and without textures
- [x] Fully working export of NSBMDs
- [x] Exporting fully custom models to NSBMD
- [ ] Importing separate NSBTXs for textures
- [ ] Export of meshes using Quads/Tri-strips/Quad-strips (Currently everything is triangulated)
- [ ] Export of textures
- [ ] Proper Material Editing
- [ ] Importing custom textures
- Later
  - [ ] Bone Animations (NSBCA) Support
  - [ ] Texture Animations (NSBTP) Support
  - [ ] Material Animations (NSBMA) Support
  - [ ] Visibility Animations (NSBVA) Support
  - [ ] Texture SRT Animations (NSBTA) Support
